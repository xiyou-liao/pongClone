# Ditto Pong Game

This is my own version of the classic Pong game! 

## Instructions

- Player 1 controls: W and S
- Player 2 controls: Up and Down

- To toggle between single and multiplayer modes: press t
  - In single player mode, you can only control the left side paddle. 
  - The right side paddle will move based on the position of the ball closest to it.

- To choose number of balls in play: press a number key from 1-3
